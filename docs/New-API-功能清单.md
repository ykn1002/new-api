# New API 功能清单

> 💡 本清单依据《New API 功能指南》整理，按"用户端 / 管理员端 / Root 系统配置"分层罗列全部功能点，供功能梳理、需求对齐、测试覆盖与验收勾选使用。
> 模块编号规则：用户端 U、管理员端 A、Root 配置 R。
> 导入飞书后，可使用飞书右侧「大纲/目录」功能快速跳转各模块。

## 附录：计费核心规则

| 项 | 规则 |
| --- | --- |
| 配额单位 | 1 美元等于 500,000 配额点数 |
| 按量计费 | （输入 Token 加 输出 Token 乘补全倍率）乘模型倍率乘分组倍率 |
| 按次计费 | 模型固定价格乘分组倍率乘 500,000 |
| 缓存计费 | 缓存读取按折扣计费，缓存写入按基础价倍数（5 分钟/1 小时 TTL） |
| 工具计费 | Web 搜索、文件检索等工具调用附加计费 |
| 表达式计费 | 单模型单表达式承载阶梯/动态/分项定价 |
| 倍率优先级 | 用户专属倍率大于分组倍率大于默认倍率 |
| 计费机制 | 预消费预扣加后消费按实际重算加多退少补 |
| 失败退款 | 调用或任务失败全额退还配额 |

> 💡 统计（v1.1）：用户端约 75 项、管理员端约 70 项（含参数覆盖 20 项、渠道亲和 5 项）、Root 配置约 90 项，合计功能点约 235 项。
